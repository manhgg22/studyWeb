# studyWeb

Web học tập dựng bằng Next.js (App Router) + TypeScript + Tailwind. Hiện đang ở giai đoạn khởi tạo.

## Chạy

```bash
npm install
npm run dev     # http://localhost:3000
```

| Lệnh | Việc |
|---|---|
| `npm run dev` | dev server |
| `npm run build` | build production |
| `npm start` | chạy bản đã build |
| `npm run lint` | ESLint |

## Trạng thái

Mới có khung dự án, chưa có tính năng. Code nằm ở `src/` và `app/`.
